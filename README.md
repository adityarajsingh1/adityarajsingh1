# Hi, I'm Aditya 👋

**AI Engineer · building LLM apps, RAG systems and agents on a data engineering foundation**

I've spent 6 years in software and IT services delivery, mostly in data engineering and analytics. Day to day that means Python, SQL, Apache Spark and ETL pipelines that move and clean large datasets, and Power BI and Tableau dashboards that turn the results into something people can act on. I like the whole journey from raw, messy data to a decision someone can actually make with it.

Lately I've been going deep on generative AI. Rather than just calling an API and moving on, I'm building small, hands-on projects to understand how LLMs work under the hood: training a GPT from scratch, building RAG systems piece by piece, and writing an agent without any framework. Everything is open source below, and each README explains what I learned along the way.

I enjoy deep work, keep learning, and work best in a team that iterates quickly. Always happy to connect with people working on data, ML or LLM applications.

## 🤖 What I've been building

| Project | What it is |
|---|---|
| [offshore-wind-gpt](https://github.com/adityarajsingh1/offshore-wind-gpt) | A GPT built from scratch in plain PyTorch (my own BPE tokenizer, transformer, pretraining and fine-tuning), trained only on offshore wind text. |
| [local-pdf-rag](https://github.com/adityarajsingh1/local-pdf-rag) | Chat with your PDFs fully offline using Ollama and ChromaDB. Nothing leaves your machine, and every answer cites file and page. |
| [chat-with-pdfs](https://github.com/adityarajsingh1/chat-with-pdfs) | RAG built by hand in four small files: PDF chunking, embeddings, numpy search, and answers from Claude or GPT with page citations. |
| [research-agent](https://github.com/adityarajsingh1/research-agent) | A tool-using research agent in about 100 lines, no LangChain. It searches the web, reads the pages and writes a sourced report. |
| [mnist-classifier](https://github.com/adityarajsingh1/mnist-classifier) | Handwritten digit recognition from a plain MLP up to a CNN at 99.6%, plus a script to test it on my own handwriting. |
| [local-cloud-assistant](https://github.com/adityarajsingh1/local-cloud-assistant) | A Streamlit chat app that switches between a local Ollama model and Claude or GPT, even mid-conversation. |
| [model-face-off](https://github.com/adityarajsingh1/model-face-off) | Ask Claude, GPT and Gemini the same question and compare answers, speed and token usage side by side. |
| [terminal-chat](https://github.com/adityarajsingh1/terminal-chat) | A small terminal chatbot for Claude, OpenAI, Gemini or a local model. Where this whole series started. |

**🚧 In progress:** LLMOps (building, deploying and monitoring LLM apps), agent evals (measuring accuracy and hallucination), and an LLM router that picks the right model for each request.
